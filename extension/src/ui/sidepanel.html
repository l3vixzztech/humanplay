      Open a chess.com game — every move that lands is explained here.

        templates · no key needed

        One factual sentence per move — both colours — built from Maia's probabilities and the rules (never a judgement, never an engine claim). Templates work with no key and no network; Groq/Gemini only rephrase the same facts and need the provider host permission (requested when you pick them) plus a key. The API key is stored in chrome.storage.local only and never logged. No TTS here (future).

        voices: checking…

        Reads the suggested move aloud on your turn — "just the move" ("Knight to f3"), no probabilities. Speech runs in the service worker, so it keeps working while this panel is closed. Ctrl+Shift+Y toggles TTS; the toolbar badge shows TTS while it is on. Default: off.

        Elo

        Maia-3 is conditioned on both players' Elo (0–5000, trained on human games; clamped). Changing them re-analyzes the current position — the probabilities (and sometimes the top move) change with Elo.
